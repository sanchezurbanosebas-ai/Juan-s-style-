Mapa de Navegación - Aplicación Barbería
Nivel / Pantalla Ruta Sugerida Rol Permitido Funcionalidad Clave
Home (Pública) index.html Público General Presentación del negocio, catálogo de servicios y acceso rápido a reserva.
Login / Registro login.html Público / Clientes Formulario con autenticación por correo y contraseña (hash). Redirecciona según `id_rol`.
Panel Cliente cliente/mis-citas.php Cliente (Rol 2) Consultar citas activas, botón para Cancelar y modal para Aplazar fecha/hora.
Panel Administrador admin/agenda.php Admin (Rol 1) Agenda general del día, control de estado (`confirmada`, `completada`), y bloqueo manual de turnos.
Guía para el aprendiz:

Al procesar el formulario de login, el script backend verifica el rol: si id_rol == 1 envía a la ruta de administración; si id_rol == 2 envía a la vista del cliente donde puede gestionar sus citas agendadas.
